# NAVIG plugins

> **Generated, read-only mirror.** The source of truth is the NAVIG monorepo; this repo is
> force-pushed from it by `scripts/mirror-plugins.mjs`. **Do not open PRs here** — they cannot
> be merged and will be overwritten on the next sync. File issues, and send changes, upstream.

First-party plugins for [NAVIG](https://navig.run). Some are **navig extensions** (installing one
pulls in navig and adds a `navig <verb>`); some **run on their own**, with no navig at all.
Each plugin's README has the install lines, its commands and a demo where one exists.
